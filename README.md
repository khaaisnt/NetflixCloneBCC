# Netflix Clone BCC By Rakha Adrian

Landing page sederhana bertema Netflix menggunakan HTML, CSS, dan JavaScript.

## Fitur

- Tampilan hero section dengan ajakan berlangganan.
- Navigasi desktop dan hamburger menu untuk tampilan mobile.
- Informasi layanan Netflix.
- Daftar film dan acara TV populer.
- Pilihan paket Basic, Standard, dan Premium.
- Form pendaftaran email.
- Layout responsif untuk desktop dan mobile.
- Animasi menggunakan AOS (Animate On Scroll).

## Teknologi

- HTML5
- CSS3
- JavaScript
- [Google Fonts](https://fonts.google.com/)
- [AOS](https://michalsnik.github.io/aos/)
